# 🎮 Tic-Tac-Toe Web Application  

A classic **Tic-Tac-Toe** (X & O) game built using **HTML, CSS, and JavaScript**! 🕹️  
Simple, fun, and a perfect project to practice front-end web development skills.  

---

## 🚀 Live Demo  
👉 Just open `index.html` in your browser and start playing!  
*(You can also deploy it on GitHub Pages, Netlify, or Vercel for online play.)*  

---

## 🛠️ Tech Stack  

- 🌐 **HTML** → Page structure  
- 🎨 **CSS** → Styling and responsive layout  
- ⚡ **JavaScript** → Game logic & interactivity  

---

## ✨ Features  

- 🎲 3×3 Tic-Tac-Toe grid  
- 👥 Two-player (local multiplayer)  
- ✅ Automatic win & draw detection  
- 🔄 Restart option (reset the board)  
- 📱 Responsive design (works on desktop & mobile)
